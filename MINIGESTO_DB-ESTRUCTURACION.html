¿Cómo se busca un registro? (flujo de una consulta)

El usuario pide userID = X desde main.
BPlusTree baja por nodos internos; cada nodo se lee con RequestPage(pageID, READ).
La hoja devuelve el blockID donde está X (par userID → blockID).
BufferPool entrega el bloque: si no está en RAM lo lee de disco con readBlock y desaloja por LRU si no hay frames libres.
Se busca X dentro de los registros de esa página y se devuelve.
